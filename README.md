# DeepSeek Harness × 飞书/微信 收藏系统（微信式收藏系统）

本项目为 DeepSeek Harness 机器人（dsh-superagent）在飞书（Feishu）中实现的“微信式收藏系统”，仿照 workbuddy 的微信收藏助手提示词。

## 结构

- `COLLECTION_PROMPT.md`：收藏助手提示词（Feishu Collection Prompt），定义自动收藏、分类、保存去重、回复规则。
- `dashboard.html`：本地网页看板（读取 `collection_record.json` 并展示分类统计与收藏列表）。
- `collection_record.json`：统一的收藏总记录（JSON 数组）。
- `公众号/`、`小红书/`、`抖音/`、`随手收藏/`：四类收藏文件夹（实际收藏内容文件可放在对应目录）。

## 快速开始

1. 初始化收藏系统：
   - 在本地知识库根目录（默认 `D:\workbutterfly\个人知识库\`）下创建四个分类文件夹。
   - 创建统一收藏总记录文件（JSON）。
   - 用 `dashboard.html` 作为本地网页看板。
2. 通过飞书/微信分享文字、图片、链接给机器人。
3. 机器人按 `COLLECTION_PROMPT.md` 规则自动分类、保存、去重，并回复 `已记录`。

## 规则摘要

- 分类：可确认来源的进入对应文件夹；无法识别或普通内容进入 `随手收藏`。
- 保存：完整保留原文、链接、时间；图片保存原件；相同链接不重复收藏；重复发送有新文字时追加，不覆盖。
- 去重：仅按“相同网址”去重；相同文字但不同链接不去重；可关联的内容自动合并。
- 回复：成功保存后回复 `已记录`；重复内容确认保存且看板正常也回复 `已记录`；失败先安全重试，仍失败说明原因，不得虚报成功。
